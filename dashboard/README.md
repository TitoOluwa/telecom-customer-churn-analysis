# Dashboard

This folder is to contain the dashboard and supporting files created for the customer churn analysis.

## Status

A dashboard has not yet been developed for this project.

## Planned Dashboard

A future dashboard may present the main customer churn findings, including:

- Churn rates by contract type
- Churn rates by customer tenure
- Customer churn reasons
- Key customer segments for further investigation

## Purpose

The goal is to make the analysis easier for business stakeholders to explore and use when evaluating customer retention opportunities.
